# Project instructions

## No tests

Do not create, modify, run, restore, or suggest tests unless the user explicitly requests a specific test.

When the user explicitly requests a test:

- Create or run only the exact test requested.
- Treat permission as valid for that request only.
- Do not treat it as permission to add or run other tests later in the session.
- Do not add a test framework, test dependency, or test script unless the user explicitly requests it.

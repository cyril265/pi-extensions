# Repository Guidelines

## Changelog

Before committing, update the root `CHANGELOG.md` with all notable changes. Within each dated release, group entries under `### <extension-name>` headings. Use `### General` for changes that are not specific to one extension.

## Sync

After each push from this repository, sync its pushed `HEAD` tree to `/Users/kpovolotskyy/ai-stuff/ai-lab/pi/`. Commit the synced files in `ai-lab`, and include the source `HEAD` hash in the commit message.
